Dark mode for websites that don’t have one.

Nyx is a free, open-source extension for Safari on iPhone, iPad and Mac, and for Chrome, Edge and Firefox. It reads the colors in each page’s stylesheets and swaps in darker ones, so you can still tell which site you’re on.

Download for Chrome, Edge or Firefox Build it for Safari

Not on the App Store or the Chrome Web Store yet. Both installs go through GitHub for now.

It starts from the page’s own CSS.

The quick way to darken a page is to invert it, which turns photos into negatives and orange bars blue. Nyx reads the page’s stylesheets instead and picks a new color for each one, depending on whether it paints a background, text, a border or a shadow.

Colors keep their hue
A blue link becomes a lighter blue, not yellow. A saturated background stays saturated and gets darker.
Cards stand apart
Light backgrounds map to a few shades of the theme’s background, so a menu or a code block is still a shade apart from the page behind it.
4.5:1Text stays legible
Colored text is lightened until it reaches at least 4.5:1 contrast with the background, the WCAG level for body text.

What you can set

  • Auto, On or Off

    Auto follows your system’s Dark Mode or a schedule, 20:00 to 07:00 by default. On always darkens websites; Off never does.

  • Per-website settings

    From the toolbar menu, give any site its own status and theme, pause it until tomorrow, or fine-tune dynamic colors, background images and image inversion.

  • Domain, subdomain or page

    Apply a setting to a whole domain, a subdomain, a host with a port such as 192.168.1.2:8080, or a single page.

  • Leaves dark sites alone

    If a site already has a dark mode, Nyx stays out of the way, and it checks again when the site switches its own theme. You can turn this off for any site.

  • Images

    Photos are dimmed to the theme’s image brightness, and grayed out if the theme sets grayscale. Small dark icons on transparent backgrounds are inverted so they don’t vanish.

  • Keyboard shortcuts

    Toggle the current site, step it through Auto, On, Off and Default, pause it until tomorrow, cycle themes, or set the global status.

  • iCloud, Shortcuts and Control Center

    Settings sync between your Apple devices through iCloud. You can also change them from Shortcuts, a Focus Filter or a Control Center control.

Nyx collects no data.

Nyx has no servers and no accounts, so there is nowhere for your browsing to go.

  • No analytics, ads, crash reporting or third-party SDKs.
  • Settings live on your device and sync only through your own iCloud account.
  • The only network requests Nyx makes are for stylesheets and images the page already loads, to read their colors.
  • The code is on GitHub under the MIT license if you want to check any of this.

Install from GitHub for now

Nyx isn’t on the App Store or the Chrome Web Store yet. For Safari, build it from source with Xcode. For Chrome, Edge and Firefox, download a zip from the latest GitHub release or build it with Node.js.

Safari

Build the Nyx app with Xcode for iPhone, iPad or Mac, then turn on the extension in Safari.

  1. Clone the repository and follow the steps in apple/README.md.
  2. Run the app on your Mac, iPhone or iPad.
  3. Turn on Nyx in Safari’s extension settings. The support page shows where.
Safari build instructions

Chrome · Edge · Firefox

Download nyx-chrome or nyx-firefox from the latest release, or build the extension with Node.js:

npm install
npm run build
  1. Chrome or Edge: unzip the download, open chrome://extensions, turn on Developer mode, choose “Load unpacked” and pick the unzipped folder (or dist/chrome if you built it).
  2. Firefox: open about:debugging, choose “Load Temporary Add-on” and pick the zip (or dist/firefox/manifest.json).
